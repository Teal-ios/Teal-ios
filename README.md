## 👨🏻‍💻 소개

- iOS와 Android 앱을 함께 개발하며 플랫폼별 특성과 공통된 사용자 경험을 모두 고민합니다.
- 운영 중인 서비스의 기능 개발부터 구조 개선, 안정성 확보까지 제품의 전 과정을 다룹니다.
- 기존 구조를 존중하면서 점진적으로 더 명확하고 유지보수하기 좋은 코드로 개선하는 것을 중요하게 생각합니다.

## 🏃🏻 현재 개발하고 있는 서비스

### 랭킹마라톤

걷기와 달리기 기록을 기반으로 랭킹, 도전, 리워드를 제공하는 모바일 서비스입니다.<br>
iOS와 Android 앱을 함께 개발하며 다음 영역을 중심으로 제품을 개선하고 있습니다.

- **위치 기반 러닝** — GPS 수집, 러닝 세션 상태 관리, 이동 경로와 영역 시각화
- **지도 기능** — Mapbox 기반 경로 렌더링과 땅따먹기 콘텐츠 구현
- **플랫폼 간 기능 일관성** — iOS와 Android의 기능 흐름, API 응답 처리, 사용자 피드백 정합성 개선
- **멤버십과 인앱 결제** — StoreKit과 Google Play Billing 기반 구매·복원·구독 상태 처리
- **서비스 안정성** — 인증 갱신, 네트워크 예외 처리, 캐시 정책과 오류 대응 개선
- **글로벌 서비스 대응** — 다국어 UI와 로케일별 표현, 긴 번역문을 고려한 유연한 레이아웃 구성
- **개발 생산성과 품질** — 테스트 보강, 모듈 경계 정리, CI/CD와 빌드 검증 환경 개선
